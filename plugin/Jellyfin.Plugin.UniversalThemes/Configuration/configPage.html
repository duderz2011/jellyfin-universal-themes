Universal Themes & Genres — v0.5

Manage the preferred theme and search movies or TV shows by existing Jellyfin metadata. This page does not move, rename, or edit media files.

Theme selection is saved for future compatible clients. Official native apps cannot be restyled by server CSS.
Uses metadata genre labels. Movies and shows remain in their original folders.

Apply web theme

Download the selected CSS from your public GitHub theme repository and copy it to the clipboard. Back up existing CSS, then paste it in Dashboard → Branding → Custom CSS. This is deliberately not automatic.
