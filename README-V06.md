# Universal Themes v0.6 test package

Jellyfin 12.2.0 / Windows. Includes three streaming-inspired CSS files, a standalone viewer-facing genre homepage, a Windows web viewer copy script, and an update to the Jellyfin plugin's built-in configuration HTML.

**Not a replacement for Jellyfin Web's default homepage** and **not a native-app theme**. Open the optional viewer URL from the updated dashboard after installation. It uses a separate Jellyfin login and reads only the signed-in user's library. Theme selection inside that viewer is independent of plugin preferences in this release.

See `docs/V06-WINDOWS.md` for installation, testing and rollback.
